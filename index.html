Kalau data di sini terasa ketinggalan, cek dulu riwayat run di tab Actions pada repository GitHub proyek ini — di situ kelihatan jelas apakah proses sync terakhir sukses atau gagal, dan kenapa.
Alur otomatisnya:
  1. Tim edit stok/harga langsung di file Excel stockpositionreportdetail.xls di OneDrive, lalu simpan.
  2. GitHub Actions mengecek OneDrive tiap ±2 menit, mengunduh versi terbaru.
  3. Data diproses jadi data.json mengikuti mekanisme yang sama dengan sheet SOH di Sales Dashboard toko (kategori DEVICES/ACCESSORIES + sub kategori PHONE/TABLETS/LAPTOPS/WATCH/EARPHONES/HEADPHONES).
  4. Kalau ada perubahan, hasilnya di-commit ke repository dan Netlify otomatis publish ulang website ini.
  5. Halaman ini sendiri mengecek data.json secara berkala (lihat Preferensi) dan hanya me-refresh tampilan kalau memang ada perubahan.
Catatan penting: ini near real-time, bukan instan sepersekian detik — ada jeda maksimal seukuran interval cek GitHub Actions (~2 menit) ditambah waktu Netlify publish (biasanya beberapa detik). Kalau butuh update paksa segera, buka tab Actions di GitHub lalu klik Run workflow.
